# AI Learning Agent v3.3.2 收口计划

> 更新日期：2026-10-26
>
> 状态：阶段 A、B 已完成；阶段 C–D 待执行
>
> 原则：不新增功能，不做大规模重构，不扩展到后续版本能力

## 1. 需求基线

当前需求以 [v3 架构设计](architecture.md) 中的 R1–R11 为准：

- R1–R8：核心功能；
- R9–R11：已经交付的增强功能。

现有历史阶段 v3.0–v3.3.1 已完成，详细过程保留在
[v3 项目说明书](../项目说明_v3.0.md)。

## 2. 阶段状态

| 阶段 | 目标 | 状态 |
|---|---|---|
| A | 需求、状态、决策和范围对齐 | 已完成 |
| B | 两个低风险架构修正 | 已完成 |
| C | 真实外部环境验收 | 待执行 |
| D | 发布收口 | 待执行 |

## 3. 阶段 A：文档对齐（已完成）

- 核心需求、增强需求、历史 P0/P1/P2 已建立映射；
- v3.0–v3.3.1 已标记完成状态；
- ETag、自动备份、自测来源和版本号等过期描述已修正；
- 飞书以外的推送渠道、模型批量摘要和后续版本能力已移出当前范围；
- 已实现的技术选择已从“开放决策”改为“已定实现决策”；
- 架构文档已记录当前实现偏差，但没有把它们描述成设计目标。

阶段 A 不修改业务代码，不产生运行时行为变化。

## 4. 阶段 B：最小架构修正（已完成）

只执行两个行为保持型任务：

### B1. 删除重复安全中间件（已完成）

- [x] 删除重复的 `install_security_headers(app)` 调用；
- [x] 增加回归测试，确认安全响应头只安装一次；
- [x] 不改变 CSP 内容。

### B2. 消除模块循环（已完成）

- [x] 解除 `agent.context_builder` 与 `agent.prompts` 的循环依赖；
- [x] 不改变模型上下文和 Prompt 内容；
- [x] 相关测试、全量离线测试和循环扫描通过。

阶段 B 完成后应保持所有公开 API 和业务行为不变。

## 5. 阶段 C：真实环境验收

不开发新功能，只验证现有链路：

1. 真实模型完成一次文档问答和引用；
2. 真实 RSS 生成当天 Digest；
3. 真实飞书接收 Digest，并验证重复触发的幂等；
4. 真实 RAG 完成收藏、入库通知、检索和引用；
5. 重启后检查对话、Digest、画像、笔记和复习状态；
6. 执行 SQLite 备份恢复；
7. 运行 Docker Compose 和每日任务脚本。

结果写入 [验收与演练记录](verification-log.md)。失败项先记录，阶段 C 内只修复阻塞
对应验收的问题。

## 6. 阶段 D：发布收口

- 只修复阶段 C 暴露的阻塞问题；
- 更新 README、版本号和发布清单；
- 执行离线测试、Ruff、前端检查、锁文件和迁移检查；
- 审查最终 diff 后提交；
- 推送需要单独授权。

## 7. 暂不处理

以下问题不阻塞当前个人本地版本，只在实际修改相关代码时逐步处理：

- 拆分 `V3Store`；
- 全面迁移到异步 ORM；
- 为所有 Store 增加 Protocol；
- 将 API 查询全部迁入应用服务；
- 拆分大型前端脚本；
- 引入事件总线、LangGraph、微服务或分布式任务。

这些事项不能成为当前阶段扩大范围的理由。
